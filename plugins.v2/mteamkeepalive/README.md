# M-Team 保活

M-Team（馒头）连续 **40 天不登录会删号**，而且只有「真实登录」才重置计时——用 API 访问不算。
这个插件每天用 MoviePilot 自带的浏览器在家宽 IP 上登录一次，顺手把账号数据读出来。

## 安装与配置

| 项 | 说明 |
|---|---|
| 启用插件 / 发送通知 | 总开关；通知带分享率、魔力与最近动向 |
| 保存后立即执行一次 | 保存后马上登录一次，用来验证账号密码与 TOTP |
| 执行周期 | 5 位 Cron，默认 `0 9 * * *`（每天 9 点） |
| 分享率提醒阈值 | 低于该值时通知里会带提醒，默认 1.0 |
| 最近动向校验窗口（分钟） | 登录后读 API 的 `lastBrowse`，在这个时间窗内才算成功，默认 10 |
| 复用登录态 | 默认开。保存浏览器登录态，下次直接复用，减少登录次数与异地风控 |
| 站点地址 | 默认 `https://kp.m-team.cc`，也可填 `m-team.io` 镜像 |
| API 地址 | 读统计用，默认 `https://api.m-team.cc` |
| M-Team 账号 / 密码 | 用于浏览器登录 |
| TOTP 密钥 | 二次验证的 32 位密钥（去掉空格） |
| API Key（可选） | 留空就自动用「站点管理」里 m-team 站点的「令牌（API Key）」 |

### 填哪些就够了

- 只保活：**账号 + 密码**（没开二次验证的话）；
- 开了二次验证：再加 **TOTP 密钥**；
- 想在详情页看到分享率 / 魔力：不需要额外填，插件会去站点管理取 API Key。

### TOTP 密钥怎么拿

1. 登录 M-Team → 头像 → 控制面板 → 安全设置 → 两步验证；
2. **还没开**：点开启后页面会给出二维码和一串密钥（形如 `JBSWY3DPEHPK3PXP`），复制它；
3. **已经开了**：站点不再显示 → 先解绑再重新绑定一次，绑定时把密钥抄下来；
4. 只给二维码时：点「手动输入 / 无法扫描」通常能看到密钥，或从二维码内容
   `otpauth://totp/...?secret=XXXX` 里取 `secret` 的值。

## 保活流程

```
有保存的登录态？
  ├─ 有 → 恢复 localStorage 并刷新 → 已是登录状态就直接算完成（不重复登录）
  └─ 没有 / 失效 → 打开 /login → 填账号密码 → 需要时填 TOTP → 落到 /index
之后（配了 API Key 时）
  → 读 /api/member/profile 的 lastBrowse（页面上的「最近动向」）
  → 在「校验窗口」内 = 保活成功；否则判失败并写明最近动向时间
```

## 详情页

- 四个统计卡片：分享率 / 魔力 / 上传 / 下载（分享率低于阈值会变橙）
- 一行账号信息：账号名 · 最近动向 · 上次登录 · 统计更新时间
- 最近 10 次保活记录：时间 + 成功/失败 + 说明

## 常见问题

**提示「站点要求邮箱验证码（风控触发）」**
说明这次登录被站点判定为异常环境。插件每次复用登录态后一般不会再触发；如果频繁出现：
确认 MoviePilot 与平时登录用的是同一网络（家宽），必要时在常用设备上登录一次让站点认环境。

**提示「最近动向仍是 X（N 分钟前），判定本次没真正登录」**
说明浏览器看着像登录成功但站点没认（常见于旧登录态残留）。插件会自动清掉坏存档，
下次重新用账号密码登录。

**提示「本机没有 Playwright」**
当前镜像缺浏览器依赖（官方镜像自带）。装 `playwright` 与浏览器内核，或换官方镜像。

**一直显示「登录未成功：没找到账号密码输入框」**
M-Team 登录页改版了。把页面截图发我，我更新选择器（`#username` / `#password`）。

**能不开 2FA 吗**
可以。不开 2FA 就只用账号密码登录；但只要站点风控要求邮箱验证，插件没法自动完成，
所以建议开 2FA + 继续用登录态复用。

## 说明

- 保活必须真实登录，插件不会用 API 访问来「假装」登录；
- 登录态存在 MoviePilot 的插件数据里，属于凭据，导出备份时注意；
- 参考实现：[KnowsWlf/MTeam-CLI](https://github.com/KnowsWlf/MTeam-CLI)（登录流程与 localStorage 复用思路一致）。
