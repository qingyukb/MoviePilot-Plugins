# M-Team 保活

M-Team 连续 **40 天不登录会删号**，而且只有「真实登录」才重置计时（API 访问不算）。
这个插件用 MoviePilot 自带的浏览器，每天自动登录一次保活，顺带把账号数据读出来。

## 配置

| 项 | 说明 |
|---|---|
| 启用插件 / 发送通知 | 总开关；通知会带分享率与魔力 |
| 保存后立即执行一次 | 保存后马上登录一次，用来验证账号密码与 TOTP |
| 执行周期 | 5 位 Cron，默认 `0 9 * * *`（每天 9 点） |
| 分享率提醒阈值 | 低于该值时通知里会带提醒，默认 1.0 |
| 站点地址 | 默认 `https://kp.m-team.cc`，也可填 `m-team.io` 镜像 |
| API 地址 | 读取统计用，默认 `https://api.m-team.cc` |
| M-Team 账号 / 密码 | 用于浏览器登录 |
| TOTP 密钥 | 二次验证的 32 位密钥（去掉空格），插件自己算 6 位验证码 |
| API Key（可选） | 在 M-Team 控制台「实验室」生成；不填也能保活，只是读不到分享率 |

## 保活流程

1. 打开 `站点地址/login`，填账号密码并提交；
2. 需要 2FA 时填 TOTP 验证码；
3. 落到 `/index` 且 `localStorage.auth` 有值 → 判定登录成功；
4. 若配了 API Key，读一次 `/api/member/profile` 拿分享率 / 上传下载 / 魔力；
5. 写记录、发通知。

## 注意

- 需要容器里有 Playwright（官方镜像自带；精简镜像可能没有，插件会提示）；
- **必须在家宽 IP 上跑**：M-Team 对机房 IP 会拦截，MoviePilot 一般都在家里，没问题；
- 首次配置好先点「保存后立即执行一次」，确认结果是「登录成功」再交给 Cron。
